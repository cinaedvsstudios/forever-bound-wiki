How Storyboarder works
Storyboarder turns a script into a production plan: acts, scene cards, notes, media, effects and progress.
  1. In Capsanoto, choose a document and click Send to Storyboarder. It opens here and builds scene cards automatically.
  2. Check the breakdown, add production notes, and attach your images, video or sound files.
  3. Use Save to choose a backup folder where supported, or download one portable project ZIP. It includes the project index, episode files, script copies and available media.
  4. Open a saved folder or import the ZIP to restore it. Sending a revised script retains production notes, statuses and attached media; removed scenes stay marked for review.
Browser drafts are saved per episode. Storyboarder planning is currently local to this device; Capsanoto’s Dropbox sync does not yet include these production files.
Scene Mockup is the separate frame-composition canvas. Arrange backgrounds and characters there, export an image, and attach that image to a scene here.
