## Important issues fixed

1. **Backup creation could fail outright.** The filing manifest called the missing `documentType` function. It now uses the existing document type function. Backup payload and restoration paths are exercised in tests.
2. **Unreadable browser saves were deleted during startup.** Startup now retains the original data, stops with a recovery message, and offers the original save as a download.
3. **All writing was held in a small localStorage entry.** Project documents now use IndexedDB. Existing localStorage data migrates without deleting the legacy copy. Failed writes show a persistent warning, keep the in-memory draft, and offer a download. Concurrent tabs cannot silently replace a newer save.
4. **Project changes could keep a previous HDD folder attached.** Folder connections now belong to a project, replacement detaches them, and opening a folder binds it only after a successful read. Creating a new backup requires an empty folder.
5. **Disk writes could omit inactive files or drop edits made during a write.** Folder snapshots include every file and queue changes received while writing. The complete project index is published last and contains original editor HTML.
6. **Backups lost information by round-tripping through Markdown.** Original HTML, parent relationships, source-tab metadata, and document styles now travel in project backups. Markdown remains a secondary representation. Windows line endings in frontmatter are handled.
7. **General file import and onboarding were missing.** Added a three-step project wizard, previews and tab selection, Word support, nested Google Docs imports, duplicate-tab checks, Add file, Open project, and previous-copy recovery.
8. **Storage controls described a Google Drive destination.** The main project UI now treats Google Docs as an import source and offers optional Dropbox account storage. Dropbox uses per-account connections and revision checks for uploads.
9. **Imported HTML could contain active content.** Editor rendering and imports use a pinned HTML sanitizer. Word conversion happens locally in the browser.
