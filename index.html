    Capsanoto Guidebook

    What Capsanoto is

    Capsanoto is a lightweight structured writing environment for large lore projects and long-form worldbuilding. It is designed for human writing first: fast editing, readable files, local-first autosave, simple JSON/HTML portability, and low complexity.

    Capsanoto is not meant to become a heavy database/wiki application. Its systems should stay as UI-layer writing tools unless a feature truly needs more structure.

    Application structure

    The intended hierarchy from biggest to smallest is:

    Application → Writing Room → Folder → Tab → File → Transclusion Card (TCard)

    Application
    Capsanoto itself: the static browser writing app.
    Writing Room
    A project/profile container for one story world or writing space, such as Forever Bound Writing Room.
    Folder
    A filing-cabinet category inside a Writing Room, such as Characters, Locations, Items, Worldbuilding, or Episodes.
    Tab
    A grouping inside a folder, such as Main Characters, Recurring Characters, Season 1, Songs, or Lore Checks.
    File
    An actual writing document, such as Mel, Luca, Ironvale, Runestones, or Episode 01.
    TCard
    A reusable Transclusion Card embedded in files or referenced in multiple places.

    Launch links and files

    Launcher/default entry
    index.html opens Capsanoto from the repository root or deployed site root.
    Direct editor entry
    editor.html opens the word program directly and supports deep links such as editor.html?doc=episode-01.
    Alternate direct entry
    writing-room.html opens the same UI under a Writing Room filename.
    Starter content
    content/documents.json seeds first-run files and TCards.
    Preview config
    config/auth.json exists for future auth/password work. The current preview opens without the password gate.

    Writing Room / Filing Cabinet

    The Writing Room button opens the floating Filing Cabinet. This is where folders, tabs, files, metadata, trash, and deprecated versions are managed.

    Edit mode
    Click the pencil to unlock inline editing. In edit mode you can type over the Writing Room title, folder names, tab names, file names, and metadata pill values.
    Save layout
    When edit mode is on, the save-layout icon stores the current Filing Cabinet position and size so it reopens in the same place.
    Folders and tabs
    Use the folder and tab buttons to create containers. Tabs sit between folders and files.
    Lock symbols
    The lock button on a folder or tab marks it as kept open/expanded.
    Jump rail
    The gray circle rail on the right acts like a custom scrollbar. Clicking a folder icon expands that folder and scrolls to it. The top rail button collapses all; the bottom rail button expands all.
    Trash
    Deleted files move to Trash instead of disappearing immediately. Trash is visually separated with a dark-purple header.
    Deprecated versions
    Deprecate stores an older version of a file under that file, so you can create a newer version without losing the old one.
    Duplicate
    Duplicate creates a copy of a file for variants, rewrites, or version experiments.

    Top bar controls

    Capsanoto title and icon
    The top-left title shows the Capsanoto icon and app name.
    Status box
    The center status box explains hovered controls, cursor/selection context, and save/autosave messages.
    Format
    Hover to reveal Bold, Italic, H1, H2, Normal Text, and List controls.
    Links / Subnoto
    The Links slot currently contains a Subnoto placeholder. Link creation/editing has moved mostly to the right-click context menu.
    Insert
    Insert includes Lore Table, Horizontal Rule, Image Embed, Emoji Spark, TCard, and Emphasis.
    Search
    The search button is a placeholder for the upcoming proper search system.
    Help
    Opens this guide. The help window can be dragged/resized and edited with the pencil.
    Settings
    Opens design, download, and support/reset tools.

    Right-click context menu

    Select text in the editor or right-click an existing Link Pill to open the contextual menu.

    Bookmark / Link Anchor
    Turns selected text into a bookmark heading/anchor for direct section links.
    Transclusion
    Creates a TCard from selected text. If no text is selected, TCard insertion/management happens from the Transclusion Cards panel.
    Link
    Creates a normal hyperlink to a file, anchor, TCard, or external URL.
    Pill Link
    Creates a rounded visual hyperlink pill.
    Edit Link
    Right-click an existing link or pill to update its target.
    Pill Color
    Right-click a Link Pill to change its background/text colors.

    Links, Link Pills, and Link Anchors

    Document URLs
    Files can be opened by URLs like editor.html?doc=Character-Mel-Ameldra.
    Link Anchors
    Heading IDs create section routes like editor.html?doc=Character-Mel-Ameldra#Runestones.
    External links
    Normal URLs such as https://example.com are supported.
    TCard links
    TCard targets can use block:Item-Runestones or {{Item-Runestones}}.
    Link Pills
    Link Pills are rounded hyperlinks. They no longer show an automatic arrow prefix.

    Transclusion Cards / TCards

    TCards means Transclusion Cards. TCards are the primary modular content container system in Capsanoto.

    Purpose
    A TCard stores reusable text once and displays that same text wherever the TCard is referenced.
    Syntax
    Use {{Item-Runestones}} to reference a TCard inside a file.
    Insert TCard
    The Transclusion Cards panel inserts the selected TCard at the saved cursor position.
    Style controls
    The TCard panel includes background, border, text color, heading color, and text-size controls.
    Inline edit
    Rendered TCards show an edit button on hover; clicking it opens that TCard in the side panel.
    Drag/move
    TCards can be dragged up/down inside the writing area.

    Tables

    Tables insert at the cursor, use rounded corners, and can be dragged within the document.

    Hover edit
    Hover over a table for about one second to show the table edit control. When the mouse leaves and edit is not open, it vanishes.
    Inline table tools
    Click the table edit icon to reveal popup tools for add row, add column, delete row, delete column, widen columns, background color, and border color.

    Emoji picker

    The Emoji Spark button opens an emoji grid. Click an emoji to insert it at the saved cursor position. Right-click an emoji in the grid to copy it to the clipboard instead.

    Emphasis boxes

    Highlight text and use Emphasis to wrap it in a bordered emphasis block. Emphasis boxes can be dragged in the writing area and bulk-styled from the file card color action.

    Document editing and autosave

    Document title
    The title field edits the current file title and is intentionally only slightly larger than an H1 heading.
    Writing area
    The main editable page supports browser rich-text editing, headings, links, images, tables, TCards, and emphasis boxes.
    Autosave
    Changes save to browser localStorage. The status box shows saving/autosaved messages.
    Reset Local Save
    In Settings → Help, this clears the browser autosave and reloads starter content.

    Download and backups

    Download builder
    Choose files and/or TCards, reorder them as pills, then download selected pieces.
    Caps file
    Downloads structured JSON for Capsanoto/Caps workflows.
    TXT
    Downloads plain text.
    HTML
    Downloads a browser-readable HTML file.
    Word
    Downloads a Word-compatible .doc HTML document.

    Design settings

    Settings → Design controls button colors, borders, text colors, text size, background image, dialog colors, status bar colors, emphasis box colors, panel colors, label text, dynamic text, scrollbar colors, and favorite colors. The designer is laid out as controls on the left and a sticky preview column on the right.

    Fonts are standardized: UI and writing text use Arial; code-like text uses Courier New.

    Planned workflow systems

    Subnoto
    A placeholder menu item has been added. The workflow will be defined later.
    Slash commands
    Planned examples include /dialogue, /scene, /song, /spell, /tba, /pill, and /tcard.
    Timeline blocks
    Experimental secondary system for year/date blocks that collect linked events, scenes, and TCards.
    Search
    The top-bar search button is present as a placeholder for the upcoming search interface.

    Technical notes

    Code type
    Static HTML, CSS, and plain JavaScript. No framework build step is required.
    Main app file
    app.js handles state, events, autosave, routing, TCards, links, downloads, dialogs, Filing Cabinet behavior, table tools, emoji picker, and design settings.
    Styles
    styles.css controls the theme, layouts, panels, typography, and CSS variables.
    Local storage keys
    forever-bound-writing-room-v2 stores files/TCards, capsanoto-design-settings-v1 stores design settings, and capsanoto-writing-room-layout-v1 stores Filing Cabinet panel position/size.
