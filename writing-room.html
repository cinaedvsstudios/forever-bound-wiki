Capsanoto Guidebook

What Capsanoto is

Capsanoto is a lightweight browser-based word app for large lore projects, long-form worldbuilding, and linked narrative documents.

Named functions

Document Switcher
Moves between lore documents loaded from ?doc=Document-ID.
Command Bar
The single-row toolbar. Related commands are grouped into dropdowns.
Anchor Rune
Creates a heading bookmark with a direct section URL.
Path Link
Creates a portable hyperlink to a document, bookmark, transclusion block, or external URL.
Link Smith
Edits the selected link target without recreating the link text.
Pill Gate
Turns selected text or an existing link into a rounded pill hyperlink.
Link Breaker
Removes the selected link while keeping its visible text.
Canon Block
Reusable transclusion content referenced with {{Item-Runestones}}.
Archive Export
Downloads the current local workspace JSON for backup or later sync.

Icons and PNG buttons

Most buttons use emojis first. Any toolbar button can also use a PNG by adding data-icon-src="path/to/icon.png".

Reusable Content

Transclusion Blocks

Create reusable blocks with IDs like Character-Name, Item-Name, Location-Name, or Mechanic-Name. Reference them in documents with {{Item-Runestones}}.
